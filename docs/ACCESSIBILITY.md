# Accessibility (a11y) Guidelines

- All interactive elements must have clear focus rings (`focus-visible:ring-2`).
- Image tags must supply accurate `alt` descriptions.
- Semantic HTML5 landmark elements (`header`, `nav`, `main`, `footer`, `section`, `aside`) must be utilized.
- Color contrast ratio must achieve WCAG 2.1 AA (minimum 4.5:1 for normal text).
