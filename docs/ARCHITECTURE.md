#  Project Architecture

## Overview
Single-page application (SPA) built with React, TypeScript, Tailwind CSS, and Vite.

## Structure
- `src/components/`: Reusable UI elements, layout components, and landing page sections.
- `src/pages/`: Top-level route views (Home, Rajagiri, Call for Papers, Attractions, Travel, Gallery, Accommodation).
- `src/data/`: Static conference datasets, milestones, timeline, and secretariat details.
- `src/styles/`: Global styling and design system tokens.
